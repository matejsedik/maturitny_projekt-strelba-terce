# aplikacia-android

Mobilná aplikácia pre Android (Kotlin, Jetpack Compose, Room). Spája sa priamo s terčom cez Bluetooth LE. Externý snímač zvuku (začiatok a koniec streľby, čas výstrelu): umiestnenie a spôsob pripojenia sa ešte dohodnú s učiteľom. Popis obrazoviek, databázy a štatistík je v dokumente 03_APLIKACIA.

**Stav:** priečinok je prázdny. Projekt sa vytvorí v Android Studio (Fáza 0 – inštalácia nástrojov, Fáza 1 – prvé kroky a prvá aplikácia s Bluetooth a LED). Android Studio treba pri vytvorení projektu nasmerovať práve do tohto priečinka.
